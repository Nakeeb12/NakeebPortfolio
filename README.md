# NakeebPortfolio

Personal portfolio website for **Nakeeb Ahamed**, Associate QA Lead at IPOSG (Colombo, Sri Lanka).

A static site in plain HTML, CSS and JavaScript, with no build step or dependencies.

## Features

- Responsive layout from phone to desktop
- Light and dark themes that follow the system setting, with a manual toggle
- Animated "test run" terminal in the hero
- Experience timeline, expertise cards, education and certifications
- Works without JavaScript and respects reduced-motion settings

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.

## Deploy

The site is hosted on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
